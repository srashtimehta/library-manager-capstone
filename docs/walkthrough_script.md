# 60–90 Second Walkthrough

1. Show the repository root and README.
2. Open `include/Library.h` and `src/Library.cpp` to show the separated architecture.
3. Run the program and list books.
4. Search for a title/author.
5. Issue a book and show the report.
6. Return the book and show the updated report.
7. Run automated tests and show `All library tests passed.`
8. Show CMake/Makefile and finish on the repository structure.
